# pentagon-paqc-proofs

**Status: computer-assisted proof candidate (for the stated cells), not peer reviewed.**
Version 1.0 (1 November 2026). Author: Puyi Sun (ORCID [0009-0004-1644-5300](https://orcid.org/0009-0004-1644-5300)).

## Problem
For a planar domain Ω let F(Ω) = λ₁(Ω)·|Ω|, where λ₁ is the first Dirichlet eigenvalue of the Laplacian.
The Pólya–Szegő conjecture (1951) says that among all pentagons the regular one minimises F. Its value is F\* ≈ 18.9191043.
The conjecture is open.

## Result
This repository does **not** prove the conjecture. It contains:

1. **A method (PAQC)** that certifies F(P) > F\* simultaneously for *every* pentagon P in a six-dimensional box ("cell")
   of the shape chart V₀=(0,0), V₁=(1,0), (V₂,V₃,V₄)=x ∈ ℝ⁶. It uses only:
   - the first eigenvalues of the 64 corner pentagons of the box;
   - exact matrix inequalities from a piecewise-affine transplantation onto a fixed reference fan:
     an exact covariance identity and a Loewner-order matrix Efron–Stein bound.

   All quantities are evaluated in ball arithmetic. Two forms are used: a single scalar "min-corner" inequality, and a
   stronger "T1" inequality checked by a second-order Taylor branch-and-bound over the cell.
2. **Six certificates for five distinct boxes at three centres.** Two certificates apply the two methods to the same
   box, and two boxes are nested in larger ones; the repeats are kept as method comparisons. The centres are the cell
   identified as hardest in a published outward-continuation prototype, a point at chart distance 0.1, and the hardest
   of 480 random centres of our own cost sweep. See `paper/paper.pdf`, Section 5.
3. **A partial independent second-party replay** (paper, Section 7), by checkers that share no source with the
   producer: the regular-pentagon upper bound, the convexity gates, the geometry factors and the corner eigenvalue
   bounds of certificates A and B, and the leaf-tree coverage of C–F. The whole-leaf bounds of the T1 certificates (C–F)
   have **not** been replayed independently. `replay_status.json` says exactly what has been replayed and how.
4. **An estimate of the cost of covering a whole region** (paper, Section 6), for one labelling of each pentagon (the
   Dirichlet domain of the D5 relabelling action). It is an estimate, not a certificate; data and code are in `cost/`.

## How to verify
Tested with: producer side Python 3.13.17, python-flint 0.9.0, NumPy 2.5.3, SciPy 1.18.1 (Linux x86_64); second-party
side Python 3.14, mpmath 1.3.0, NumPy 2.5.4, SciPy 1.18.1 (WSL2 Ubuntu). Do not run Python with `-O` (the checks are
`assert` statements).
```
sha256sum -c MANIFEST-SHA256.txt
pip install python-flint==0.9.0 numpy==2.5.3 scipy==1.18.1 mpmath==1.3.0

# producer replay of all six cells from the saved corner certificates (about 15 CPU minutes)
cd producer && python3 verify_certificates.py && cd ..

# independent corner-eigenvalue checker (second party) on cells A and B, 128 corners
# (about 3-5 CPU minutes per corner; resumable)
cd second_party
mkdir -p lines/D-topics/probes/PENT/G1/replay_corners
ln -s ../../../../../../../certificates/replay_corners/all lines/D-topics/probes/PENT/G1/replay_corners/all
python3 q1_batch_mu_guard.py --N 300 --corners 64 --files 2 --workers 4
cd ..
```
The corner checker expects its data under `lines/D-topics/probes/PENT/G1/replay_corners/all/` (the research
repository's layout); the link above provides it.

## Changes since 1.0-rc2 (not published)
- Section 6: the band [0.02, 0.05) averaged only over the centres that passed; its three failed centres lie outside the
  domain D and must count as zeros (found by the second party). Its estimate drops by 2.2%; r in [0.05, 0.6) is
  unchanged. The estimator now stops if a failed centre lies in D. The formula is described as an unbiased estimate of
  a continuum proxy, not of the number of boxes of a real cover.

## Changes since 1.0-rc1 (not published)
- Section 6: rc1 divided the volume of a shell around the regular pentagon by 10 for the D5 symmetry. Relabelling is
  not an isometry of the chart, so that was wrong (found by the second party). The estimate now counts cells of the
  Dirichlet domain of the action, which contains about 71% of the sampled centres, and gives bootstrap intervals; the
  central estimate is about six times the rc1 figure. The data and the estimator are now included (`cost/`).
- The second party's P2 finite-element bound is marked as a historical log: its trial vector was not kept.
- `MANIFEST-SHA256.txt` now also covers the second party's FEM logs (rc1 skipped every `.log` file outside `producer/`).
