## Common coordinates, scaling, hypotheses

Q=(0,0),(1,0),q₂,q₃, y=q₂y,h=q₃y,D=q₂×q₃,K=D+y−h,M=D−h,ℓ=h−y; a=y+D=2|Q|. Cut at j=3 or 0, t,u∈(0,1). Relevant members require strict convexity and kept cut, except exclusions that explicitly show not kept. In std the base is longest; edge charts include additional convex members, not necessarily longest-base. FP §§1–3 derives charts and common-direction separate derivatives: coordinate differences are separately affine, and all vertex velocities are parallel in a given coordinate. Cross products and signed area therefore separately affine. Any such scalar is a convex combination of corners with tensor barycentric weights, and vertex coordinates likewise. Squared projection differences are separately convex. `label_exact.quad` L28–38 uses integer scale s=D_grid² (do not confuse D_grid with the determinant D); invariants y,h,K,D,M,ℓ stored in units s², area2 in same units. `pent` L39–47 uses scale D_grid³, area2 then in its square. Ratios with like units are invariant. `PI2` L10–14 lower bound π² uses Machin formula 16 atan(1/5)−4 atan(1/239), alternating enclosures, floor on positive π². `TRI=4*PI2/sqrt3_up` is strictly below 4π²/√3 (rational upper sqrt checked by squaring). The target T = exact F*_up = 18.919134195733914; inequalities against this rational use no floating-point acceptance. `dirs` contains numerically *chosen* integer directions, not numerical acceptance: any nonzero direction is legitimate.

## (a) empty / V

**Statement.** If one of y,h,K,D has maximum ≤0 over the 16 w corners, there is no strictly convex Q in the box. `label_exact.ear_ranges` L48, `check` L197–200; `proofs24b.label_direct` L182–188, `q_direct` L230–233.

**Proof.** By FP §2, consecutive edge crosses of CCW quadrilateral are y,K,D,h, all strictly positive. FP §3 corner interpolation gives each invariant ≤ its maximum, so one is nonpositive throughout. No relevant strict convex member is present; cut parameters and F bounds are irrelevant. In q coverage a missing part is permitted only with the same empty test (`q_audit.convex_possible`). A V handoff is not a certificate for nonconvex shapes. Same rule as FT/FP §5 V, §4 root exclusion; generalized to direct q and all labels in r3.

## (b) closed / lower_quad

## (c) T and TX threshold

**Statement.** In `proofs24b.label_direct` L191–205 and `label_exact.check` L207–226, let c=cut≥t·u for T; for TX choose `g=min(untouched bounds)` and restrict to kept members, which obey t·u≤g. **Proof.** The omitted triangular area is t·u·D/2 or t·u·h/2. Thus |P|/|Q|=1−t·u·τ_j. Domain monotonicity of Dirichlet λ on P⊂Q gives F(P)≥F(Q)(1−t·u·τ_j)≥lb·den (lb nonnegative for the bound used). `cut=sup t sup u` uses nonnegative t,u∈[0,1]. For TX, each finite `untouched` ratio upper g is obtained from sup numerator and inf positive denominator; if t·u>g then a competing ear strictly smaller, so cannot be kept. If no finite g, code default 2 forces conservative bounds; no useful certificate can come from the default without satisfying strict test. τ_3 increases in D and decreases in y>0: sup D/(max(0,inf y)+sup D). τ_0 ≤ sup h/inf a when inf a>0; clip upper with 1; fallback 1 valid for both (0<τ<1). ## (e) triangle_joint — new correlated polynomial sufficient inequality

`proofs24b.groups4` L165–169; `triangle_joint` L171–180, `label_direct` L206. For one of the four ear triples in (b), assume C>0 on whole w-box. Let a=y+D, p=a−cD (j=3) or a−ch (j=0), c=cut, c<1. Then 2|P|≥p and 2|T_triangle|=a+AB/C. For strict convex relevant Q, a>0,A,B>0,C>0. Therefore F(P)≥TRI·p/(a+AB/C) by P⊂Q⊂T_triangle (for kept TX use c bound from (c)). To force >T, it suffices that `TRI*p*C−T*(a*C+A*B)>0`. The variables are four affine-chart coordinates; each of a,p,A,B,C is multi-affine by FP §3. Write each as tensor degree-one Bernstein sum over corners `f_i` times `b_i`. Then product coefficient for multi-index γ∈{0,1,2}⁴ equals sum over pairs i+j=γ of f_i g_j divided by ∏ binom(2,γ_k), a strictly positive divisor; every degree-two Bernstein basis is nonnegative and sums to 1. `groups4` records these pairs without normalization. All 81 grouped coefficients strictly positive imply polynomial strictly positive everywhere including boundaries. Uses classical ear and triangle from FP §§1,6, but this joint Bernstein inequality is r3's new route; independent of table and tighter than separate extrema.

## (f) q_strip / rect_strip — nonstrict threshold and strict B margin

`proofs24b.rect_strip` L77–85; `label_direct` L208–212; `q_direct` L234–235. With nonzero fixed integer n, v_i vertex, width W_n=max n·v_i−min n·v_i, area2 A, if `PI2 |n|² A_corner ≥ 2 L W_corner²` at each corner, then for every pair of vertices the polynomial `PI2 |n|² A−2L(n·(v_i−v_j))²` is separately concave (A separately affine, projection difference separately affine, L>0). FP §3 Lemma 6 gives ≥0 on whole box; maximizing pair yields the bound at any convex member. Poincaré strip gives F≥π² |n|² A/(2W²)≥L; W>0 for strict convex positive-area member. **`>=` plus `any(a>0)` by itself does not prove strictness** (e.g. equality for the conservative constant at a corner; `any` does not force a uniform margin). For q_other, only ≥L is needed; this is adequate even with degenerate zero-area corners, as proof never divides by their W. Actually PI2<π² and positive area/width yield strictness for any valid member if L>0 and inequality holds, but no need to use this to close the table. In B T/TX, code explicitly boosts L to `(T/den)*(1+10^-10)`, so F(Q)≥L gives strict F(P)>T. `any(a>0)` is an extra sufficient filter, not the strictness argument. New q threshold route based on FP §5 S(a), §6 strip. Target positivity required; frozen q lower bounds positive (see structure and task input).

## (g) fibre_route: q_fibre / P_fibre

`proofs24b.hull_setup` L104–115, `fibre_route` L117–161, `trans` L96–102, fixed-point L90–95. FL Lemma OD/PS and Families. H = convex hull of every corner vertex; interpolation contains every convex member, including ones with some nonconvex corner samples. am=min signed double area corners; am>0 ensures positive area lower bound am/2. For nonzero integer direction d, n=|d|², coordinates (dot(p,d),cross(d,p)) scale by sqrt(n); global x range w>0 and h>0; after translate and divide both by w, x∈[0,1], eigenvalue of original H is n/w² times normalized eigenvalue. For N=0 rectangle containing H gives λ≥PI2*n*(1/w²+1/h²), then ×am/2. Otherwise nodes are grid i/N plus all hull x-breakpoints, N=16,32,64,128,256. Upper line minimum minus lower line maximum is true section width of convex H at x; on each interval between breakpoints width affine, so W=max endpoint widths bounds it. If W=0 on an entire segment no positive-width section exists; on interior of nondegenerate hull this cannot occur. Set m=2w²*target/(am*n)*(1+10^-10), cap=m+4/step²; v=min(PI2/W²,cap), cap when W=0. This is a lower potential: capping only decreases the valid lower bound; not a proof that |z|≤4 automatically, since v can be far below m. `trans` checks |z|≤4 explicitly, else refuses. m>0, v≥0. OD: apply fibre Dirichlet Poincaré to u_y, integrate in y,x; after zero extension use 1D Rayleigh infimum for u_x with potential π²/width². Potential monotonicity gives λ_norm(H)≥μ((0,1),v). PS: if φ solves −φ''+vφ=mφ piecewise and C¹ with φ>0 interior, substitute f=φg for compactly supported f, integrate by parts; ∫(f'²+vf²)−m∫f²=∫φ²g'²≥0, proving μ≥m. Nonnegative step potential and piecewise continuous derivative make integration legitimate. For a segment step hₖ, z=(v−m)hₖ², C(z)=Σ z^k/(2k)!, S(z)=Σ z^k/(2k+1)!, exact transfer `(φ,φ')→(Cφ+hₖSφ', (v−m)hₖSφ+Cφ')`. 80-bit fixed-point enc/mul/div round outward for both signs; series truncate after k=20, each tail ≤2·4²¹/42!<2^-80, so expand by one absolute unit. At all right nodes lower bound φ>0; first φ(0)=0,φ'(0)=1. If v≥m, affine/hyperbolic solution has at most one zero unless identically zero (uniqueness); positive endpoints rule out a simple sign-changing zero. If v<m then phase √(m−v)h≤2<π, at most one zero, same argument. First segment explicit sin/κ, sinh/κ or x positive for positive x; all subsequent endpoints positive. Thus φ>0 interior. Finally F(member)≥(am/2)*(n/w²)*m=target*(1+10^-10)>target; applies separately to q and P. `q_fibre` in B uses target T/den, `P_fibre` direct T. Breakpoint grid and cap relative to m are new in r3; analytic OD/PS existing FL. For q_other no strict margin required (provided target positive). Direction search merely proposes integer d; replayer reruns same exact potential, transfers and positivity.

## (j) splitting and witness semantics
