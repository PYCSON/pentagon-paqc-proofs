### A2. 盒子一阶多项式：实际实现

`code/lg_exact.py` 为纯标准库 proof kernel，`lg_search.py` 可选 SciPy 数值候选，`lg_stdlib.py` 为标准库候选生成（以逆迭代、Cholesky、Ritz 导数、对偶乘子搜索替代 NumPy/SciPy）。两引擎统一使用完全相同的有理接受判据。对归一化参数 x_i∈[-1,1]，z=m+r*x 选 u^0+Σx_i u^i 和 χ^0+Σx_i χ^i；O 固定在中心多边形的有理重心。近区及三种切角图卡、四边形图卡使用规格中的映射。Ritz 变分导数数值解仅用于提出系数；任何误差可能降低通过率，但不能放宽严格接受条件。

独立构造整数稀疏多项式：几何坐标共同分母 S，det_k = D_k/S²，面积=ΣD_k/(2S²)，Dprod=∏D_k。试探系数、参考积分统一分母 G。令 A1_num 对应 A1=A1_num/(G S²)，A0_num 对应 A0=A0_num/(G Dprod)，A2_num 对应 A2=A2_num/(G S⁴ Dprod)。KS=K/J、目标 L=F/H。则

```
A1d = A1_num * Dprod
PD_num = 2K*A1d - J*(ΣD_k)*A0_num
PC_num = H*(ΣD_k)*PD_num - 2F*(2K*A2_num - J*(ΣD_k)*A1d)
```

所有缩放因子严格为正（det_k>0 后），与规格 PD=Dc*𝔇、PC=C*𝔇 的符号一致。检验绝对系数界；或严格有理 LDL^T 检验 H_poly+2diag(μ) 正定、μ≥0，再用精确 Hessian 对偶减高阶系数绝对和。无需点采样替代正性。切分为最多64个闭子盒，逐支重展开（整数二项式），保留每支 μ。二分全部子盒严格通过才认整盒通过。见证保存 u/χ 全整数列表、目标/盒数据、每子盒对偶参数及全系数哈希。`replay.py` 可纯标准库重新建多项式并核对哈希、输入盒及目标绑定。

非零归一化角点代入后，固定同一 O，重建点形状及对应线性系数并严格比较整数缩放的 PD、PC：near 6,298/13,031 项；std 15,151/30,754 项；qstd 511/885 项；3/3 PASS。这里是同一数学公式的独立点代入交叉检查，不冒称完全不同 Green 公式第二后端。初始对照误用了重新计算的 O，失败日志保留，固定同一 O 后重跑通过。`python -S code/replay.py` 独立标准库样本 23/23 PASS（7 near + 8 far + 8 q）。`--engine stdlib` 新生成两张正式盒各 1/1 PASS（near 8 个子盒，8.1322s；qstd 直接，0.1368s）。其全量速度未实测。SciPy 是可选非标准库候选生成途径，实测大样本用它；所有接受均是标准库严格算术。

几何前提：det 全正的 winding number 必须由一个简单成员/严格凸成员建立。近区结构和鲁棒中心余量重证确保每一个 LG 叶与 Lemma S 的开球相交；远区/四边形只对其严格凸成员断言，不把自交 pentagram 作为简单域。Lemma S 的点位扰动与 Hausdorff 距离论证可用。若脱离此图卡/前提单独调用 replay，不能从 det 全正自动推出单连通简单域。
