## 二、加载输入、实测与命题 S

独立从单位边长正五边形构造 `c=(1.309016994374947424..., 0.951056516295153572..., 0.5, 1.538841768587626701..., -0.309016994374947424..., 0.951056516295153572...)`。

重标号映射以复数表达：保向 `φ_{j,+}(z)_k=(w_{j+k}−w_j)/(w_{j+1}−w_j)`；反向需再复共轭 `φ_{j,−}(z)_k=conj((w_{j−k}−w_j)/(w_{j−1}−w_j))`，k=2,3,4。这十种在 c 固定；其 Jacobian 组成 D₅ 的六维表示。群平均 M 是投影 M²=M；标准傅里叶 mode 0 是平移，mode 1 是旋转和缩放，均已被归一化剔除，剩余模式没有全群不变向量。因此 M=0 **是解析结论**，数值检查并非唯一依据。

若 U(c)=L(c)=F₀、L≤F=F◦φ_g≤U◦φ_g，且 L、U 在 c 可微，令 z=c+td，分别从 t>0 与 t<0 的群平均上界，得到 `∇L(c)·d=0`，所以 ∇L(c)=0。因为 Ψ(c)=0 且分母在 c 正，∇Ψ(c)=0；F 不必预先可微。固定的试探函数及积分在可逆星形扇区图卡下给出 z 的有理函数，故光滑条件成立。

## 三、真族可容许性与 Proposition R 的重推

设在参考三角形 `h=(2+E)^{-1}v`，`s=(-det·a h+∂_bχ, -det·b h−∂_aχ)`。有 `-div_r s=det·v`。对参考扇形边，`-(p−O)h` 沿边切向，curl χ 的法向是 χ 的切向导数；χ 在扇形间连续 H¹，故分布意义没有辐条 delta。O 处由 `h` 的 L²/径向积分估计可控制通量，没有孤立点 delta。正五边形的 corner 正则性 `r^{5/3}` 不阻碍 H¹ 论证。由于 `div(∇u₀/λ₀+(p−O)h₀)=−u₀+u₀=0`，单连通 Lipschitz 域存在 H¹ stream potential χ₀（模常数）。

令 `P=|P(z)|, λhat=F₀/P`, `ρ=N_z s̃−∇ṽ/λhat`, `t=s̃−s_true`, `e=ũ₀−u₀`；源为 e 的 t 与源为 ṽ 的 s̃ 均满足 IP。于是

```
a_z(ṽ,e) = λhat [b_z(ṽ,e) − ∫ρ·M_z∇e]
c_z(s̃,t) = ∫ρ·t + λhat^(-1)b_z(ṽ,e)
B_z((ṽ,s̃),(e,t))
 = P(κ+F₀)b − P²λhat b − F₀κ λhat^(-1)b
   + F₀ P∫ρ·M_z∇e − F₀κ∫ρ·t
 = F₀ P∫ρ·M_z∇e − F₀κ∫ρ·t
```

因为 `P² λhat = PF₀`、`F₀κ/λhat=κP`，四个 b 项完全抵消。令 `t_c=M_c(ρ_c+∇e/λ₀)` 且 `t_z=t_c−(det_z−det_c)(a,b)e_h`，再展开 `B` 的平方得到正文 K、Λ、Θ、q，**所有符号与系数一致**。

自写 `proposition_r_quadrature.py` 使用人工多项式 `e=a b(1−a−b)` 和非平凡 χ，真实对为零、计算对为 e，分别用 n=10/15/23 高斯积分直接计算。完整残差表达式应为零，误差分别 `3.94e−15,3.94e−15,2.17e−15`；两次 IP 精确到 `5.2e−19`。这是代数试验，不声称重放真实的 ε₁ 证书。

## 四、§5 三不等式细节

1. 若 `u₀=Π₁ũ₀` 为真一阶特征子空间的 L² 投影，e 正交于该空间，因此 `A₀(ũ₀)−λ₀ A₁(ũ₀)=||∇e||²−λ₀||e||²`。
2. e 处于高阶谱子空间，所以 `||∇e||²≥λ₂||e||²≥(κ/|P(c)|)||e||²=ν||e||²`。当 `A₀<ν A₁`，u₀ 的投影不为零，且 `ε₁² ≤ (A₀−λ_lo A₁)/(1−λ_up/ν)`（要求分母严格正）。正五边形面积约 1.720477400589，ν约 21.120201321773；存档 `ε₁=0.001014412367, ε₀=0.000220732107` 的关系吻合。
3. 每条射线 `h(s)=s⁻²∫₀^s t e(t)dt`。Cauchy 给出 `s³|h|² ≤ (s/2)∫₀^s t|e|²dt`，交换积分可得 `∫₀¹s³h² ds ≤ ¼∫₀¹t(1−t²)e²dt ≤ ¼∫₀¹ te²dt`。自造 e=a b(1−a−b) 的精确有理积分之比为 `707/6000≈0.1178333<1/4`。

## 七、文献与证明范围

1. X. Liu 的公开仓库 https://github.com/xfliu/polya-szego-conjecture 已包含全部横截单位方向 `t≤1/6250` 的局部极小证明与可重放代码，并在论文中明确使用 Lehmann–Goerisch 的一向量版与 RT₁ H(div) 通量。Theorem L 不宜宣称“首次使用 LG/真特征函数局部极小”，应具体区分 LG 的真实参考函数残差消去、显式半径和多项式球证书。数值比 `0.05/(1/6250)=312.5`，但两者方向坐标及范数不相同，未经转换不能把它当成同一度量下的严格半径增益。
2. B. Bogosel, D. Bucur, *Polygonal Faber-Krahn inequality: Local minimality via validated computing*, https://arxiv.org/abs/2406.11575，给出五边形的 10D Hessian 六个非平凡正特征值的验证区间（按 D₅ 对称性三个重数二）。它们的基底、面积归一化、相似群商度量与本稿的六维固定边图卡不同，**原始特征值不能逐个直接相等比较**。要比较需构造对应切向 Jacobian 并作一致的广义特征值转换。
3. 非凸简单五边形不能仅由 `P⊂conv(P)` 推出目标 F 的单调性：`λ₁(P)≥λ₁(conv P)` 与 `|P|≤|conv P|` 的乘积方向相反，尚没有由本三片计算推出非凸情形的归约。故就算三片都通过，严谨称谓应是**全体凸五边形的 Pólya–Szegő 不等式**，不是未经补充的全体五边形 conjecture。参见 Bogosel–Bucur 2024, https://jep.centre-mersenne.org/articles/10.5802/jep.250/ 。
